# 🛡️ AI Surveillance System

An AI-powered real-time surveillance system built using **React (Frontend)** and **Python Flask (Backend)**.  
This system streams live video, detects faces, and records surveillance footage.

---

## 🚀 Features

- 📹 Live Video Streaming
- 🧠 AI Face Detection
- 📂 Known Faces Recognition
- 🎥 Recording Storage
- 🔌 REST API Integration
- ⚡ Real-time Status Monitoring
